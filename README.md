# SQL Portfolio - Sakila (Business Case Analysis)

This repository contains a business-oriented SQL analysis using the Sakila database.

## How to run

This repo is self-contained: `sqlite-sakila.sqlite` is a ready-to-use SQLite database, so there's no setup beyond opening it.

```bash
sqlite3 sqlite-sakila.sqlite < basic-exercises.sql
```

Or open `sqlite-sakila.sqlite` directly in any SQLite client (e.g. [DB Browser for SQLite](https://sqlitebrowser.org/)) and run the queries from `basic-exercises.sql` one at a time.
